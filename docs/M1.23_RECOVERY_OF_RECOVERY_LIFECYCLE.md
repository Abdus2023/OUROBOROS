# M1.23 — Recovery-of-Recovery Authority Lifecycle

## Status

M1.23 defines the authenticated lifecycle of the independent N-of-M authority
introduced by M1.22. The quorum is externally provisioned at genesis, but its
membership and threshold are no longer treated as immutable configuration.

## Security boundary

```text
External quorum root
        │
        ▼
Current quorum epoch / membership
        │
        ├── signer rotation
        ├── signer revocation
        └── threshold change
        │
        ▼
Authenticated lifecycle statement
        │
        ▼
Ordered durable journal event
        │
        ▼
Next quorum epoch
```

The initial quorum remains an external root. A repository-local file, event, or
checkpoint cannot manufacture the first quorum authority.

## Operations

| Operation | Effect | Epoch |
| --- | --- | --- |
| `ROTATE_SIGNER` | Replace one authorized signer with fresh key material | +1 |
| `REVOKE_SIGNER` | Remove an authorized signer | +1 |
| `CHANGE_THRESHOLD` | Change quorum threshold without changing membership | +1 |

Every operation is signed by at least the **current** threshold of the current
quorum. The statement records the exact source epoch, so a statement authorized
under an older quorum cannot be replayed after lifecycle mutation.

## Normative invariants

1. **External genesis** — the initial quorum MUST be provisioned outside the repository.
2. **Authenticated mutation** — no lifecycle mutation is valid without signatures from the current quorum.
3. **Exact epoch** — a lifecycle statement MUST name the current quorum epoch exactly.
4. **Single-step continuity** — every accepted lifecycle statement advances the epoch exactly once.
5. **Fresh rotation** — signer rotation MUST use a previously unused key ID and new public-key material.
6. **No empty quorum** — the final signer MUST NOT be revoked.
7. **Satisfiable threshold** — membership changes and threshold changes MUST leave `1 <= threshold <= member_count`.
8. **Signer authorization** — every statement signer MUST belong to the quorum at the statement's source epoch.
9. **Unique signers** — duplicate signer identities MUST be rejected.
10. **Canonical binding** — operation, epoch, target, replacement material, threshold, reason, and algorithm are all signed.
11. **Ordered replay** — lifecycle events MUST be replayed in journal order.
12. **No retroactive authority** — a later quorum membership change MUST NOT authorize an earlier lifecycle or break-glass event.
13. **Durable evidence** — the lifecycle statement MUST be carried by an unscoped journal event before it can affect recovered authority.
14. **Root separation** — the recovery-of-recovery epoch is independent from the ordinary trust-store and emergency-recovery epochs.
15. **Fail closed** — malformed, stale, duplicated, unauthorized, or unsatisfiable lifecycle state MUST prevent recovery rather than selecting a best-effort authority.

## Authority vocabulary

- **CURRENT** — quorum state reconstructed from the external genesis quorum plus every valid prior lifecycle event.
- **STALE** — a statement references an older quorum epoch and therefore cannot authorize current state.
- **INVALID** — the statement fails structural, cryptographic, membership, or threshold validation.
- **REVOKED** — a signer removed by an authenticated lifecycle event has no authority in subsequent epochs.

## Important distinction

M1.23 does **not** make the repository the root of the recovery quorum. It only
makes the externally rooted quorum itself evolvable under its own authenticated
policy. If every current quorum signer is compromised, M1.23 cannot recover the
system by itself; M1.22's independently provisioned recovery-of-recovery
mechanism remains the authority for replacing the emergency recovery root.

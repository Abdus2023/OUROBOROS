# M1.25 — Authoritative Checkpoint Issuance

## Status

Implemented hardening slice.

## Problem

Current authoritative bootstrap replays trust, emergency-recovery, and recovery-quorum history through one fail-closed state machine. Checkpoint issuance previously used the narrower trust replay path, so a caller could issue a checkpoint while silently omitting the externally rooted recovery-quorum authority from issuance-time validation.

That creates an authority asymmetry:

```text
bootstrap       → authoritative recovery replay
checkpoint      → trust-only replay
```

A checkpoint is security-sensitive external evidence and must not be issuable from a weaker reconstruction path than the path that later consumes it.

## Rule

When an external recovery quorum is supplied to `issue_current_checkpoint()`, issuance MUST use `recover_authoritative_state()` with the complete externally provisioned recovery root and recovery quorum.

Therefore:

```text
external genesis
      ↓
trust state
      +
recovery root
      +
recovery quorum
      ↓
ordered authoritative replay
      ↓
checkpoint issuance
```

A wrong or inconsistent quorum now prevents checkpoint issuance instead of producing a checkpoint that can only be diagnosed as invalid later.

## Scope

This slice deliberately does **not** yet add the recovery-lineage digest to the signed checkpoint schema. The next slice should bind the reconstructed recovery-root/quorum state itself into signed checkpoint evidence, making the relationship explicit rather than relying on the signed journal-head binding alone.

## Regression coverage

The conformance suite verifies:

1. checkpoints for quorum-bearing histories are issued through authoritative replay;
2. a rogue externally supplied quorum cannot issue a checkpoint for another quorum's journal history;
3. current checkpoint recovery still requires the same quorum authority;
4. malformed or unauthenticated quorum history remains `INVALID`, not `STALE`.

## Invariant

> Checkpoint issuance MUST NOT have weaker authority-reconstruction semantics than authoritative current bootstrap.
